# Portfolio de Nissrine Sghir

Site statique professionnel, responsive et compatible GitHub Pages.

## Publication sur GitHub Pages

1. Créez un dépôt GitHub et ajoutez-y tous les fichiers de ce dossier.
2. Dans **Settings > Pages**, choisissez **Deploy from a branch**.
3. Sélectionnez la branche `main` et le dossier `/ (root)`, puis enregistrez.

Le formulaire et les créneaux sont prêts visuellement. Pour recevoir des messages et automatiser les rendez-vous, connectez respectivement Formspree et Calendly.
